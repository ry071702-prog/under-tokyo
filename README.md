# UNDER TOKYO 🚇

**東京の地下を、断面で見る** 鉄道路線が地面の下をどう潜っているかを、地形 (地表標高) と一緒に断面プロファイルで可視化するサイト  まずは *日本一深い地下鉄* 都営大江戸線から

> インスピレーション元: [東京断面図 (tokyo-danmenzu)](https://tokyo-danmenzu.pages.dev/) へのリスペクト
> こちらは「平面の路線図と断面を1画面で同期」「深さの色エンコード」「モバイル対応」を狙った別アプローチの実装
> **東京断面図のデータは一切使っていない** (着想のみ  詳細は「クレジット」参照)

## いま出来ること (MVP)

- **断面ビュー** — 横軸＝路線に沿った距離、縦軸＝海抜(m)  地表ラインと線路ラインを重ねて表示
- **深さの色エンコード** — 浅い(シアン)→深い(紫)  数字を読まなくても深い区間が分かる
- **同期ミニマップ** — 路線図の駅にホバー→断面側がハイライト (逆も連動)  「いま地理的にどこか」が消えない
- **深さ強調トグル** — 縦スケールの誇張 ON/OFF
- **海抜0mの基準線** — 低地区間で線路が海面下を走る様子が分かる

## ⚠️ データについて (正直な注記)

このサイトの数値は**大半が概算**です  断面の形を眺めるための図として扱ってください

- **ホーム深さ (depth) が公表値なのは4駅だけ** — 六本木 42.3m / 東中野 38.8m / 新宿 36.6m / 中井 35.1m
  `src/data/oedo.ts` で `published: true` が付いているのがこの4駅  残り34駅は**概算 (estimated)**
- **地表標高 (ground) は六本木を含む全38駅が概算** — だから公表値の4駅でも、画面に出る「線路の海抜」は概算の地表標高を引いた**概算まじりの値**になる
- 台地・谷・低地という**地形のトレンドは実地形に寄せている**が、数値そのものは暫定
- 断面で海抜0m未満に描かれる駅が多いのは、この概算の影響を受ける  「この駅は海面下」という読み方はできない
- 全38駅の縦断面 (建設記録) に基づく精緻化は今後のフェーズ

### 公表値の出典と、その限界

- 「駅の深さ」の定義 = 駅中心位置の地表からホーム面までの距離 (東京都交通局による定義として引用されているもの)
- 4駅の数値は [東京のモグラ駅、深さランキング TOP10](https://tabi-mag.jp/underground-stationtk/) に載っている値
  **この記事は定義の出どころを東京都交通局としているが、表の数値そのものの一次資料は示していない**  孫引きである点に注意
- 六本木の 42.3m は大門方面ホーム  新宿方面ホームは 32.8m という報道がある ([乗りものニュース](https://trafficnews.jp/post/131168))
- **東京都交通局が全38駅の深さを一覧で公表している資料は、2026年11月時点で見つけられていない**  各駅の公式ページにも深さの記載はない

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 型チェック + 本番ビルド (dist/)
npm run preview
```

技術: Vite + TypeScript (フレームワークなし)  断面=Canvas、ミニマップ=SVG
デプロイ想定: Cloudflare Pages (`npm run build` → `dist/` を配信)

## ロードマップ

- [ ] 地表標高を国土地理院DEMタイルから自動取得 (概算 ground を実測へ  **取得時は国土地理院の利用規約に従い出典を明記する**)
- [ ] モバイル: 断面を**縦倒し** (スクロール方向＝深さ方向)
- [ ] 路線比較モード (複数路線を同一スケールで重ねる)
- [ ] 走行モード (駅通過アニメーションで「体験」側に振る)
- [ ] **都内全路線**へ拡張 (平面図は ODPT/OSM、断面はデータを起こせる路線から  **OSM を使う場合は ODbL、ODPT は公共交通オープンデータ協議会の利用規約に従い、いずれも出典表示を入れる**)

## クレジット

- 「路線を断面で見る」という着想は [東京断面図](https://tokyo-danmenzu.pages.dev/) から得ました  **同サイトのデータ・数値・コードは使っていません**  同サイトのデータを二次利用・派生公開するには個別の相談が必要とされているため、このリポジトリの数値はすべて自作の概算と上記の公表4駅のみで構成しています
